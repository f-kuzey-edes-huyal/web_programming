# PHOTO ALBUM PROJECT

This folder contains two versions of the same photo album project:

1. **basic**  
   A modal photo album **without keyboard events**

2. **keyboard**  
   A modal photo album **with keyboard events**

## Project Purpose

This project demonstrates how to build a simple photo album using HTML, CSS, and JavaScript.  
Both versions allow the user to open images in a modal window and navigate through the album visually.

The second version extends the first one by adding keyboard support for easier navigation.
